# akhilreddy1636.github.io

Personal portfolio of **Akhil Reddy Donakonda**, Full Stack Developer (Node.js · React · RabbitMQ · Redis · Asterisk · LLMs).

**Live:** https://akhilreddy1636.github.io

A single hand-written `index.html` with no build step and no framework. It has light and dark themes, a responsive layout and inline SVG architecture diagrams.

## Run locally
```bash
python3 -m http.server 8000   # then open http://localhost:8000
```

## Deploy
Push to the `main` branch of a repo named `akhilreddy1636.github.io`. GitHub Pages serves it automatically.
